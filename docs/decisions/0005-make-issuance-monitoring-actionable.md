# 0005 Make issuance monitoring actionable

## Decision

Present issuance change, approved term-family composition, active-data findings, quality context, limitations, and investigation prompts in one accessible local workflow.

## Why

Stakeholders need to move from trust to change to driver to next review without reading SQL or pipeline logs.

## Alternatives rejected

A static KPI report without evidence, failure states, or investigation prompts would not support an operational decision.

## Not done

The issuance dashboard does not claim longitudinal factor, runoff, prepayment, credit, or causal analytics.

## Changed

M3 added derived findings, explicit unknown handling, resilient UI states, accessibility controls, and investigation guidance.
