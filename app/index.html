How to use this project

A reproducible monthly monitoring workflow

1. Refresh

Place newly downloaded month-end issuance ZIP files in data/raw/, then run npm run load:raw.

2. Review

Use the trend to identify changes in issuance volume, security count, and average security factor.

3. Extend

Add monthly security-factor files for balance runoff and prepayment analysis without changing the public aggregate layer.
