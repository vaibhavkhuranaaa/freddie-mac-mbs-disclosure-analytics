# User-facing design rules

- Use Impeccable/design-taste guidance for every screen, dashboard, demo, and public project page.
- Use a professional, readable font available in the selected platform.
- Make hierarchy, loading, empty, error, and refusal states clear.
- Build responsive, keyboard-accessible interfaces; never hide essential meaning behind color alone.
- Use visuals to explain the project workflow, architecture, or evaluation—not as decoration.
